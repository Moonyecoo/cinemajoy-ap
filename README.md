## 📖 项目简介 (Overview)

**影悦 · 独立版 (CinemaJoy)** 是一个自主设计研发的现代桌面端影视与流媒体客户端。本项目拒绝低质嵌入与广告干扰，采用标准 HTTP 媒体流协议与底层解码渲染引擎，将电影从“单次播放内容”转变为“可以持续参与、留下记忆、交换感受并建立轻量关系的社交媒介”。

---

## ✨ 核心特性 (Key Features)

### 1. 16:9 横向高清宣传大海报 (HD Billboard Hero)
- **影院级宽银幕巨幕**：告别模糊竖图切边拉伸，采用 16:9 原画高清横版电影海报作为主视觉舞台。
- **免代理双通道刮削**：通过内置安全 DoH 通道秒级并发匹配 TMDB `w1280` 原生剧照与豆瓣精选高清背景，并配备右下角 6 卡高清缩略图平滑切换坞。

### 2. 影视圈 · 主题观影旅程与情绪共鸣 (Cine-Circle)
- **主题化连续观影旅程**：将同类经典电影编排为连续旅程站台，同步点亮个人观影进度足迹。
- **跨源时间轴动态校准**：自主研发 `calibrateMomentTime` 算法，在跨不同转码片源、正片片头时长差异下，毫秒级自适应校准高光时刻。
- **智能防剧透保护门禁**：自动侦测播放进度达 60% 后的关键情节时刻并开启高斯模糊遮罩，杜绝剧透。
- **5 维零打字情绪回声**：提供破防、独处、震撼、封神、回味 5 维轻量共鸣徽标，免除撰写冗长影评的社交负担。

### 3. ✦ 定格此刻 · 动态视频片段与电影解说合成台 (Pin Moment Studio)
- **前后 3–5 秒动态短视频截取**：支持选择 `前后3秒(6s)` / `前后4秒(8s)` / `前后5秒(10s)` 视频片段，实时循环预览视频画面。
- **多片段按时间轴自动排序**：单部电影可多次定格精彩节点，系统自动按 `start_sec` 升序排列为结构化分镜轨道。
- **一键合并生成连续电影解说**：支持一键启动解说串播，播放器自动按时间顺序跨片段无感跃迁，同步浮现解说字幕横幅与 Web Speech 语音解说旁白；支持录制导出 `.webm` 高光视频。

### 4. 新片专栏 · 60+ 部实时电影解说流 (Movie Articles & Commentaries)
- **多源并发实时汇聚**：从多个直连源并发聚合最新上映大片与深度视频解说（单次拉取 60+ 部）。
- **分类筛选标签**：按今日最新、悬疑惊悚、科幻动作、高分剧情等维度快速切换。
- **深度影视精读专栏**：内嵌深度赏析文章流与全屏原生长文阅读器，支持一键空降正片播放。

### 5. 纯净流媒体内核与免代理高速专线 (Streaming Core)
- **真实码率底层仲裁**：内置 `ffprobe` 流特征解析引擎，严格区分 1080P 真原画蓝光与伪高清压缩糊源。
- **国内免代理防污染专线**：无外部依赖的 DoH (RFC 8484) / HTTP-DNS 探针与 Clean IP 直通调度，彻底免疫 DNS 劫持与网络波动。
- **秒开熔断与自愈路由**：采用多臂老虎机 (Bandit) 动态评分算法，线路故障 3 次自动沉底隔离，秒切健康线路。

### 6. 跨屏无线投屏 (Cast & Stream)
- **多协议无线投屏**：原生支持局域网智能电视 DLNA 投屏。
- **WebCast 手机扫码直连**：内置超轻量本地 HTTP 串流转发服务器，手机扫码即可无缝继续观看。

## 🚀 快速上手 (Quick Start)

### 运行环境要求
- **操作系统**：macOS (Apple Silicon & Intel) 或 Windows 10/11
- **Node.js**：`>= 18.0.0`
- **npm**：`>= 9.0.0`

### 步骤指南

```bash
# 1. 克隆代码仓库
git clone https://github.com/your-username/cinemajoy-app.git
cd cinemajoy-app

# 2. 安装项目依赖
npm install

# 3. 运行全套自动化测试（必须全部通过）
npm test

# 4. 以开发模式启动应用
npm start
```

## 🧪 自动化测试与质量门禁 (Testing)

本项目推行严格的规范与测试驱动流程。交付前必须执行：

```bash
npm test
```

测试套件涵盖 21 项核心工程模块断言：
1. **网络自治与合规域名审计**：严格校验全项目网络请求，确保合规域名白名单 100% 达标；
2. **底层画质特征仲裁**：验证真 1080P/4K 原画与低码伪高清鉴别算法；
3. **安全防污染 DNS**：验证国内 DoH 解析、TTL 内存缓存与超时熔断；
4. **影视圈时刻与时间轴校准**：断言跨源秒数校准与防剧透高斯模糊；
5. **定格时刻视频与解说合成**：验证同部电影多片段自动排序与连续串播逻辑；
6. **低配硬件流畅度与内存预算**：断言运行时空闲内存基线不超过 150MB。
