# Implementation Tasks: 通用流媒体盒子聚合痛点根治与体验重塑 (007-user-painpoints-remedy)

## Phase 1: 痛点 1 & 2 - 源健康探针自愈池与真实流画质仲裁 (Tasks 1-2)
- [x] **Task 1: 零配置开箱即用与断网探针冻结自愈**
  - 在 `lib/sources.js` 与 `lib/router.js` 扩展源健康度调度与离线保护机制：
    - 内存中跟踪各源连续失败次数、实时延迟、健康评分；
    - 捕获全局离线状态，断网时冻结熔断扣分，防止网络恢复后全源被误封；
    - 默认源异常时自动降级到评分最高的健康备用源。
- [x] **Task 2: 底层流特征真实画质仲裁与低码率打标**
  - 在 `lib/prober.js` 严格执行带宽与分辨率硬指标分级：
    - 识别 720P/1080P 被伪造成 4K 的低码流（kbps < 1200 判定为 `tier: '1080P-low', isTrueHD: false`）；
    - 识别真 1080P 蓝光（kbps >= 2500 且 1080p）与真 4K 原画（kbps >= 15000）；
    - UI 渲染时明确显示「压缩低码」或金色「1080P 蓝光原画」，杜绝虚标。

## Phase 2: 痛点 3 - 播放器看门狗与无感切源接力 (Tasks 3-4)
- [x] **Task 3: 播放器卡顿看门狗状态机与防抖门禁**
  - 在 `src/app.js` 播放器内核中挂载智能看门狗：
    - 监听 `waiting`、`stalled` 及 HLS `ERROR`，卡顿停滞超 3.5s 触发自动切源；
    - 增加 60 秒冷静防抖期，单集切源上限锁定为 2 次；
    - 退出播放器或切换路由时强制 `clearInterval` 注销定时器，消除逃逸泄漏。
- [x] **Task 4: 无感平滑切源接力与 HLS 实例安全重构**
  - 在 `src/app.js` 实现自动切源接力：
    - 切源前安全执行旧实例 `hls.destroy()`；
    - 新实例严格继承防爆缓冲区参数（30s/60s/10s）；
    - 备用源若缺少当前集数自动跳过探测下一个源；
    - 新流就绪后自动 seek 回原播放秒数，屏幕顶部呈现 Toast「✦ 智能接力：已无感切至线路 2 (延迟 98ms)」。

## Phase 3: 痛点 4 & 5 - 搜索实体聚类、选集校准与桌面黄金比例 (Tasks 5-6)
- [x] **Task 5: 搜索结果同名强聚类去重与逆序选集自动升序校准**
  - 在 `lib/metadata.js` / `lib/api.js` 实现搜索聚合：
    - 同名影视依据权威元数据聚类为 1 个主条目，内部收拢多源线路；
    - 对乱序或倒序集数（如“40..1”）自动检测并升序校准为标准 1..40。
- [x] **Task 6: 16:9 / 2:3 黄金视听比例锁定与海报自愈**
  - 在 `src/app.css` 强化卡片与海报容器：
    - 严格锁定 `aspect-ratio: 16/9` 与 `aspect-ratio: 2/3`，辅以 `object-fit: cover` 杜绝拉伸；
    - 海报加载失败时经由本地 Clean IP / 安全 DoH 闭环回退，无白名单外外链；
    - 确保全局全量快捷键（空格暂停、上下音量、左右步进、F 全屏、M 静音、[ / ] 切集）毫秒级响应。
