## 1. 背景与用户核心痛点对齐 (Pain Points Mapping)

基于知乎、V2EX、开源社区用户长期真实吐槽与深度调研，传统通用流媒体盒子聚合软件的核心痛点聚焦于以下 5 点：
1. **接口频繁失效，维护门槛高**：用户三天两头找配置、求接口，老人家里根本无法自主使用。
2. **画质严重虚标，暗部马赛克与满屏赌博广告**：标 4K 蓝光实际仅 800k 码率，充斥内嵌跑马灯。
3. **播放卡顿断流，手动盲切线路反人类**：晚高峰转圈卡死后，无智能接力，强迫用户退出全屏逐个试错。
4. **搜索同名灾难，选集倒序、漏集与多季混乱**：搜一部剧出 20 个重复条目，集数倒序或混排。
5. **桌面端水土不服，海报拉伸变形与裂图**：遥控器交互生硬套在 Mac/PC 上，图片被墙后满屏灰方块。

## 2. User Scenarios & Acceptance Criteria

### User Story 1 - 零配置开箱即用与可用源动态自愈健康池 (Priority: P1)
用户下载打开「影悦 · 独立版」(CinemaJoy) 后，无需在设置中到处寻找、复制粘贴长链接通用影视源订阅配置。内置官方干净自愈源池，后台通过静默心跳探测器（每小时自动探活延迟与有效性），动态剔除死亡源、沉底慢速源；一旦某个数据源异常，前台搜索与浏览自动毫秒级故障转移至健康节点。若系统全局离线（本地网络断开），自动冻结熔断计时器，杜绝网络恢复时全源死锁。

- **验收标准 (Acceptance Criteria)**:
  1. **Given** 首次启动应用且本地没有任何自定义接口配置，**When** 打开首页或执行搜索，**Then** 应用无需任何手动配置，0 门槛自动秒出海报与剧集列表。
  2. **Given** 某默认主源遭遇 HTTP 500、404 或超时，**When** 用户发起搜索或选片，**Then** 系统健康调度器在 250ms 内静默降级熔断该源，并自动平滑路由至最高分备选健康源，用户全程无错误弹窗打扰。
  3. **Given** 本地网络完全断开（Offline），**When** 探活探测失败，**Then** 探测器识别为宿主断网并冻结熔断扣分，避免将全部正常源误判熔断进入 5 分钟死锁。
  4. **Given** 设置中心中的源管理列表，**When** 用户查看源状态，**Then** 每个源显示实时测速延迟（如 `🟢 120ms` / `🟡 650ms` / `🔴 熔断冷却中`），并提供「一键全网健康体检」按钮。

### User Story 2 - 流特征真伪画质仲裁与低码率防欺诈标识 (Priority: P1)
在解析与播放 m3u8 时，底层流特征探测器（prober）严格检测视频的真实分辨率 (width x height) 与码率 (kbps)。只有真实码率 >= 2500kbps 且分辨率 >= 1080p 的视频才标记为「1080P 蓝光原画」；低于 1200kbps 的虚标视频在 UI 明确标注「压缩低码」，绝不欺骗用户。同时提供去广告与字幕安全区保护。

- **验收标准 (Acceptance Criteria)**:
  1. **Given** 采集端将 720P/1080P 低码率流恶意重命名为“4K 蓝光”，**When** 仲裁器解析流特征，**Then** 准确判决为 `isTrueHD: false` 并赋予 `tier: '1080P-low'`，界面清晰展示「压缩低码」，杜绝画质虚标。
  2. **Given** 真实 1080P 且带宽 >= 3500kbps 的原画流，**When** 解析完成，**Then** 界面点亮高反差金色「1080P 蓝光原画」正品认证标识。
  3. **Given** 播放包含侧边赌博水印与跑马灯字幕的流，**When** 用户开启「纯净画面模式」，**Then** 视频画面应用边缘安全遮罩与跑马灯抑制滤镜，保护视听体验。

### User Story 3 - 播放卡顿无感智能自愈接力与防抖看门狗 (Priority: P1)
播放器挂载智能看门狗：一旦播放过程发生卡顿缓冲停滞超过 3.5 秒，或者捕获到 HLS 致命网络错误，立即在后台并发探测备用线路中对应的同集数，并在 1.5 秒内自动切换线路并精准 Seek 恢复到原播放秒数。为防止频繁抖动，单次自动切源后进入 60 秒冷静期，单集最大自动切源次数限制为 2 次；若备用源缺少当前集数，看门狗自动顺延跳过该源探测下一可用源。切源前完整安全销毁旧 HLS 实例，防止内存泄漏。

- **验收标准 (Acceptance Criteria)**:
  1. **Given** 用户在全屏播放《星际穿越》第 42 分钟，**When** 当前线路突然断流或转圈超过 3.5 秒，**Then** 看门狗自动激活，并发探活备选可用线路，1.5 秒内平滑切入新线路并跳转至第 42 分钟继续播放。
  2. **Given** 自动切源发生，**When** 新流载入，**Then** 旧 HLS 实例安全执行 `hls.destroy()`，新实例严格继承缓冲区锁定参数（`maxBufferLength: 30`, `maxMaxBufferLength: 60`, `backBufferLength: 10`），看门狗进入 60 秒冷却防抖窗口，屏幕顶部展示轻量 Toast 提示「✦ 智能接力：已无感切至线路 2 (延迟 98ms)」。
  3. **Given** 备用源 A 存在，但该源缺少当前播放的“第 15 集”，**When** 看门狗探测，**Then** 自动跳过源 A，路由至包含第 15 集的备用源 B。若全网所有源均无该集或已达 2 次切源上限，停止自动切换并优雅保持缓冲提示，绝不造成死循环狂切。
  4. **Given** 用户退出播放器或切换路由，**When** 页面销毁，**Then** 播放器完整注销看门狗定时器与事件监听器，避免定时器逃逸。

### User Story 4 - 搜索结果权威实体聚类去重与正倒序分季归一化 (Priority: P2)
搜索时杜绝采集站原始脏数据直接平铺。所有同名结果按照规范化片名与权威影视库（TMDB / 豆瓣）ID 强聚类，同名影片仅展现 1 个主条目海报卡，卡内收纳聚合所有来源与可用线路。选集解析器进行自动升序归一化与分季清晰化，彻底消除“倒序反人类”与“第1季和第2季混杂”的乱象。

- **验收标准 (Acceptance Criteria)**:
  1. **Given** 搜索关键词“庆余年”，全网源返回 18 个包含各种错别字、季数混乱的条目，**When** 聚类引擎处理完毕，**Then** 前台仅输出标准主条目，内部清晰分离「第一季 (全46集)」与「第二季 (全36集)」。
  2. **Given** 某源的集数列表以倒序（第40集...第1集）呈现，**When** 解析器载入剧集，**Then** 自动检测并校准为从「第 1 集」到「第 40 集」的标准正序，且支持一键切换正倒序。

---

### User Story 5 - 桌面原生黄金比例视听交互与海报防裂图安全自愈 (Priority: P2)
彻底告别电视盒子移植感。卡片严格采用 16:9 横向宽银幕与 2:3 竖版黄金比例，使用 `object-fit: cover` 锁定宽高比，杜绝海报被拉伸变形；TMDB / 豆瓣海报严格通过本地内置的安全 DoH 与已审计 Clean IP 直通加载，严禁引入未审计的境外图床域名；遇死链自动回退到本地高保真占位海报或备用 Clean 管道；全面支持 Mac 触控板平滑手势与全键盘播放快捷键（空格暂停、上下音量、左右步进、F 全屏、M 静音、[ / ] 切集）。

- **验收标准 (Acceptance Criteria)**:
  1. **Given** 任何页面卡片，**When** 浏览器缩放或窗口拉伸，**Then** 海报图均严格保持 16:9 或 2:3 比例，严禁画面拉伸、扭曲或压扁。
  2. **Given** 某海报加载抛出 error 或超时，**When** 图片加载失败，**Then** 图片管道自动降级使用本地 Clean IP 镜像并平滑回退，杜绝大片灰块裂图，且所有请求 Host 100% 满足 `audit-domains.js` 白名单校验。
  3. **Given** 处于播放界面，**When** 用户按下空格、左右方向键、上下方向键、F 键、M 键或中括号键，**Then** 播放器即时做出毫秒级响应并伴随轻量 HUD 指示器。

- 构建分发：执行 `npm run pack` 生成 `影悦.app` 并更新本地 `/Applications/影悦.app`。
