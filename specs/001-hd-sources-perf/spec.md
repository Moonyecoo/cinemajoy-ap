# Feature Specification: 影悦 · 真高清免翻墙直连源扩展与低配置流畅渲染优化

**Feature Branch**: `001-hd-sources-perf`
**Created**: 2026-11-05
**Status**: Specified
**Input**: 扩展更多真高清免翻墙直连源（真高清非虚假标注），优化低配置电脑启动与滚动渲染卡顿，提升代码执行效率与复用现有成熟开源技术。

---

## 1. User Scenarios & Testing (用户旅程与验收标准)

### User Story 1 - 畅享真 1080P/4K 高码率直连专线与画质真伪仲裁 (Priority: P1)

用户使用一台普通宽带、无需开启任何 VPN 或代理的电脑打开影视，能够直接播放真实码率在 3000kbps ~ 8000kbps 的原画电影，绝非模糊压缩假 1080P，且能清晰知晓各片源的真实画质。

- **为什么是 P1**：画质是影视客户端的立足之本，虚假标注（300kbps 标 1080P）严重伤害用户体验，免翻墙直连是国内用户核心诉求。
- **独立验收标准**：
  1. **Given** 用户点击热门电影（如《肖申克的救赎》或最新院线电影），**When** 默认播放线路加载，**Then** 系统自动选中真实测定码率最高（>= 2500kbps）的直连免翻墙专线播放。
  2. **Given** 某源流媒体实测分辨率为 1920x1080 但码率低于 900kbps，**When** 播放器画质面板展开，**Then** 明确标注「压缩版 (700kbps)」，并与标注为「真原画蓝光 (4200kbps)」的真高清源形成鲜明对比与一键切换。
  3. **Given** 用户不开启任何 VPN，**When** 访问片源 API 与音视频流切片，**Then** 100% 走纯净 HTTP/HTTPS 直连通道，免翻墙可用率 100%。

---

### User Story 2 - 低配置电脑启动零延迟与百张海报无限滚动 60FPS 流畅渲染 (Priority: P2)

用户在普通配置电脑（低配集成显卡、8GB 内存、普通 CPU）上使用客户端，软件秒开无白屏，片库滚动画布如丝般顺滑，不出现卡顿与掉帧。

- **为什么是 P2**：普通电脑在持续拉取 100+ 电影卡片时极易造成 Chromium 渲染树重排（Reflow）爆炸与内存溢出，必须从底层渲染机制根治。
- **独立验收标准**：
  1. **Given** 用户滑入电影/剧集分类并持续滚动加载多页（累计超过 120 张卡片），**When** 快速上下滚动，**Then** 利用 CSS W3C 标准 `content-visibility: auto` 与 `contain-intrinsic-size`，未处于可视视口的卡片跳过 Layout & Paint，渲染内存占用降低 60% 以上，帧率稳定在 60FPS。
  2. **Given** 应用首次启动，**When** Electron 窗口加载，**Then** 采用 `ready-to-show` 优雅渐入双缓冲机制与轻量化启动参数，冷启动时间控制在 600ms 以内，无白屏/灰屏闪烁。
  3. **Given** 本地海报图片并发拉取，**When** 瞬间遇到 30+ 张图片并发，**Then** 通过本地环回调度管道与 LRU 内存缓存，CPU 占用率峰值不超过 15%。

---

### User Story 3 - 播放链路断链毫秒级全网无感自动重连 (Priority: P3)

用户打开某部冷门老电影时，如果当前默认源出现 403 限制或 404 死链，系统在 500ms 内静默在后台探测其他可用源并平滑续播，免去用户手动一个一个切源的痛苦。

- **为什么是 P3**：网络断链或源失效是第三方公开流媒体常态，自动化秒切是保障普通用户安心观影的核心护城河。
- **独立验收标准**：
  1. **Given** 播放器收到 HLS fatal networkError（如 403/404），**When** 触发重试逻辑，**Then** 客户端立即并发探活其余片源对应剧集地址（HTTP HEAD 探测），在 500ms 内自动无缝挂载可用流并从当前断点续播，弹窗提示「已为您智能切换至可用原画源」。

## 2. Technical Requirements & Constraints (技术要求与约束)

1. **零外部竞品注解与纯净自研**：严格遵循项目宪章，禁止出现外部产品代称。
2. **轻量高效优先**：优先采用原生 CSS 特性（`content-visibility`）与原生 Node/Chromium 网络引擎，杜绝引入笨重的第三方巨型框架。
3. **测试驱动 (TDD)**：所有新增源的探测、真高清码率仲裁、启动参数与虚拟化渲染逻辑必须编写自动化测试用例，`npm test` 保持 100% 通过。
