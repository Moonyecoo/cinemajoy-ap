# Feature Specification: 影视圈情感影单生态、纯净设计系统收敛与个人中心 (006-cine-circle-ux-refactor)

**Feature Branch**: `006-cine-circle-ux-refactor`
**Created**: 2026-11-06
**Status**: Draft
**Input**: 用户需求：“把当前的热播榜改为影视圈，里面都是各种主题的电影圈，有点像歌曲的推荐歌单，每个人都可以建立自己的圈子... 顶级 ui 设计师对整个软件的 UI 彻底检查一遍，设计要统一，功能布局要合理好用。突出特点，不好用或者用处不大的功能就删除。还要有个人账号中心”

---

## User Scenarios & Testing

### User Story 1 - 影视圈 (Cine Circles) 广场与沉浸式探索 (Priority: P1)
用户点击侧边栏「影视圈」（原热播榜位置），浏览基于不同心情与主题划分的精选影单（如“深夜孤独经典”、“怀旧回声 · 8090 胶片记忆”、“雨天微醺浪漫”）。点击任意影视圈进入其专属主页，查看精选片单、情绪导语并一键播放。

**Why this priority**: 核心形态重塑。将传统生硬的热播数据榜升级为有温度、有情绪共鸣的主题影单广场，提升内容发现体验。

**Independent Test**: 用户点击导航栏「影视圈」，渲染官方主题圈列表；点击任一圈子可进入圈子主页并直接点击电影播放。

**Acceptance Scenarios**:
1. **Given** 用户在任意页面，**When** 点击左侧导航栏「影视圈」，**Then** 页面展示主题矩阵标签（全部、情绪心情、怀旧岁月、类型探索）与精美圈子卡片流。
2. **Given** 用户浏览影视圈，**When** 点击“深夜孤独经典”，**Then** 展开圈子主页，包含情绪大图 Banner、深度看点介绍、圈内影视列表（附带片名、评分、推荐理由标签）。
3. **Given** 用户在圈子主页，**When** 点击任意影片卡片，**Then** 直接进入播放页面，并自动关联可用源播放。

---

### User Story 2 - 本地优先自建圈子与去中心化便携分享 (Priority: P1)
用户可以创建属于自己的影视圈（设定圈子名称、心境分类、简介与封面主色），随时在搜索或播放时将心仪电影添加进自己的圈子；支持一键生成可分享的纯文本密令/JSON 并在任意设备无损导入。

**Why this priority**: 满足个性化收藏与社交分享诉求，且无需昂贵的云端数据库中心，0 依赖纯本地离线自治。

**Independent Test**: 新建一个“我最爱的烧脑片”圈子，加入 2 部电影，点击分享生成密令；在另一会话导入密令，100% 完整复原。

**Acceptance Scenarios**:
1. **Given** 用户进入影视圈广场，**When** 点击右上角「+ 新建圈子」，**Then** 弹出设计极简的创建弹窗，可输入标题、心情标签、导语并选择封面渐变主题色。
2. **Given** 用户在影视详情页或播放器，**When** 点击「加入圈子」，**Then** 呼出所属圈子勾选列表并实时保存。
3. **Given** 用户打开自建或收藏的圈子，**When** 点击「分享圈子」，**Then** 系统生成经过 Base64 编码的纯文本影单密令并自动复制到剪贴板，支持导出为 `.json` 影单文件。
4. **Given** 用户点击「导入圈子」，**When** 粘贴合法密令或拖入影单文件，**Then** 校验格式并即时将该圈子收录至「我的圈子」中。

---

### User Story 3 - 顶级 UI/UX 全面收敛与设计系统统整 (Priority: P2)
对全站 UI 进行地毯式设计收敛：建立统合的 Design Tokens（锁定 WCAG AAA 级对比度暗黑灰度、8px 栅格与 16px 圆角），剥离所有非必要的技术黑话与冗余边缘配置，重塑视觉呼吸感与操作流畅度。

**Why this priority**: 彻底消除拼凑感与粗糙感，让操作链路从杂乱的工具级软件升格为艺术品级现代观影终端。

**Independent Test**: 检查全软件所有页面组件，无边框设计、字体阶梯、间距、弹窗遮罩及交互动效完全一致，无任何外部技术黑话。

**Acceptance Scenarios**:
1. **Given** 用户进入设置页，**When** 浏览配置项，**Then** 仅保留核心的源管理、极简投屏开关与本地存储清理，删除所有令普通用户困惑的网络底层调试与多余日志项。
2. **Given** 用户打开任意弹窗（新建圈子、快捷键指南、投屏、高光分享），**When** 观察弹窗样式，**Then** 全部采用统合的毛玻璃 `.cinemajoy-modal` 规范与一致的动效曲线。
3. **Given** 用户缩放窗口或在低分辨率屏幕，**When** 滚动页面，**Then** 栅格自适应弹性伸缩，卡片信息层级清晰（海报、主标题、情绪小标），无错位溢出。

---

### User Story 4 - 纯本地去中心化个人账号中心 (Priority: P2)
新增个人中心模块，提供本地化身份 Profile（昵称、头像挑选、个性宣言）、自建圈子归集、追更收藏整合，并提供完整的全量数据一键备份与无缝恢复。

**Why this priority**: 给予用户强烈的归属感与数据安全感，且 100% 零隐私泄露风险。

**Independent Test**: 在个人中心修改昵称头像并导出备份；重置应用数据后通过备份文件一键还原。

**Acceptance Scenarios**:
1. **Given** 用户点击侧边栏底部个人中心，**When** 首次进入，**Then** 展示精致的个人名片卡（默认“影悦浪客”，可一键更换内置艺术头像）、我的圈子总数、追更总数与观影时长统计。
2. **Given** 用户点击「编辑资料」，**When** 挑选新头像并修改昵称与签名，**Then** 实时保存并在顶栏与圈子署名处同步更新。
3. **Given** 用户在个人中心点击「数据备份与迁移」，**When** 点击导出，**Then** 一键生成包含所有自建圈子、观看历史与收藏配置的加密 JSON 备份包；点击导入可实现跨机迁移。

## Edge Cases & Security Defenses
- **密令篡改/损坏/长度超标防御**：密令硬限制 16KB 上限，超长或非 Base64 字符输入时直接拒识；解码增加 `try...catch` 熔断，杜绝 `URIError` 或主线程假死。
- **不可信输入 XSS 深度防御**：密令解码出的 `title`、`desc`、`reason`、`author.name` 等字符串全量经过 `esc()` HTML 实体转义或以 `textContent` 写入 DOM，严禁直出 `innerHTML`。
- **低配防爆与大影单控制**：单圈收录影片设置硬上限（≤ 100 部）；列表渲染采用分批/分页机制（首屏 20 部），卡片容器显式配置 `content-visibility: auto`，杜绝 DOM 节点与显存爆炸。
- **影视源失效或下架**：自建圈子中的某部电影在当前片源搜索不到时，卡片标记「待换源」，点击时触发全网自愈探活重定向。
- **重名圈子冲突**：导入与自建重名时，自动追加 `(导入)` 后缀，保留独立 ID。
- **极端离线状态**：即使完全拔掉网线，本地个人中心、自建圈子浏览、本地数据导出等所有非流媒体播放功能 100% 正常响应。

## Requirements

### Functional Requirements
- **FR-001**: 侧边栏原「热播榜」正式重构为「影视圈」，支持按「全部 / 治愈心情 / 独处时光 / 怀旧岁月 / 高分必看」等心境主题过滤。
- **FR-002**: 影视圈必须内置至少 6 个高质量官方心境主题圈子（如：深夜治愈指南、雨天悬疑烧脑、华语经典回声、赛博朋克漫游、催泪经典、热血燃向）。
- **FR-003**: 提供完整的圈子详情视图（封面大图、作者 Profile、心境标签、简介、收录影片清单、一键连续播放、分享与收藏按键）。
- **FR-004**: 提供自建圈子能力，支持新建、编辑、删除与影片追加/移除，单圈收录影片设置硬上限 ≤ 100 部。
- **FR-005**: 提供基于 Base64/JSON 的便携影单分享契约（密令硬限制 ≤ 16KB），支持「生成分享码」与「导入分享码/文件」，具备 5 步安全解析防御流水线。
- **FR-006**: 新增「个人中心」页面，整合个人档案（昵称/头像/座右铭）、自建圈子、收藏追更与观影统计。
- **FR-007**: 提供本地数据一键冷备份与恢复功能（导出/导入 `.cinemajoy.backup.json`）。
- **FR-008**: 严格贯彻 Design Tokens 设计系统，清理全部未使用的技术黑话、冗余调试代码，统一全站 Modal、Badge、Card 与 Button 视觉规范。

### Key Entities
- **CineCircle (影视圈)**: `{ id, title, mood, desc, coverStyle, author: { name, avatar }, items: [{ id, site, name, pic, reason, rating }], isCustom, createdAt, updatedAt }`
- **UserProfile (用户个人档案)**: `{ nickname, avatar, signature, customCircles: [], favoriteCircles: [], createdAt }`
- **ShareToken (分享密令)**: 经 Base64 编码的轻量规范化 JSON，包含圈子核心元数据与影片标识。

## Success Criteria

### Measurable Outcomes
- **SC-001**: 自动化测试套件通过率保持 100%，新增针对影单模型、导入导出幂等性与个人中心的完整断言。
- **SC-002**: 新建一个影视圈并在其中加入 2 部影片的全部操作耗时在 15 秒以内。
- **SC-003**: 影单分享码长度经过轻量化压缩，体积控制在 4KB 以内，秒级完成复制与解析。
- **SC-004**: 保持脱脂性能指标：空闲内存 <= 120MB，界面切换响应时间 <= 80ms。
